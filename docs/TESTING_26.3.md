# HiveWorks — тест на Paper 26.3

Боевой сервер: Paper 26.3, Java 25.
Проверяем сборку **0.2.0-SNAPSHOT** (стабильная — 0.1.1).

## 1. Установка

1. Скачать `HiveWorks-0.2.0-SNAPSHOT.jar` (CI-артефакт `HiveWorks-latest` или локальная сборка `mvn -B -Platest clean package`).
2. Положить в `plugins/`, перезапустить сервер.
3. В логе должны быть строки:

```
[HiveWorks] Loaded 13 bee species for 26.3
[HiveWorks] SQLite storage ready: hiveworks.db
[HiveWorks] Loaded 0 hives.
[HiveWorks] Registered 8 custom recipes.
[HiveWorks] Resource pack: disabled.
[HiveWorks] HiveWorks 0.2.0-SNAPSHOT enabled: 13 species, 0 hives.
```

Ошибки `NoClassDefFoundError`, `UnsupportedClassVersionError` — сразу в отчёт.

## 3. Ресурспак и кастомный улей

1. В `plugins/HiveWorks/config.yml`:

```yaml
resource-pack:
  mode: EMBEDDED
  embedded-port: 8123
  public-url: "http://IP_СЕРВЕРА:8123"
  require: false

visuals:
  custom-hive-model: true
```

2. Перезапустить сервер и зайти заново.
3. В логе: `Resource pack: http://IP:8123/hiveworks-pack.zip (sha1 ...)`.
4. Проверить банки, рамки, мёд, ульи — должны быть кастомные модели.
5. Поставить улей: поверх блока должен появиться 3D-улей своего тира.

## 2.1. Королева

```yaml
queen:
  required: true
  max-cycles: 40
  royal-jelly-cycles: 20
  max-cycles-cap: 80
```

- `required: false` — производство продолжается без матки (для мягкого режима).
- Матка — одна из пчёл: при извлечении она уходит в банку, улей остаётся без матки.
- Маточное молочко добывается с маточной рамкой или админ-командой.

Если пак не применился: проверить доступность порта снаружи, `public-url`, firewall.
Если модели выглядят неверно — приложить скриншот в issue #6.

## 3. Что проверить отдельно

- **Перезапуск сервера:** ульи, пчёлы, рамки, мёд и атлас сохраняются.
- **Два улья рядом:** лимит 4 на чанк, 32 на игрока.
- **Чужой улей:** ПКМ открывает GUI, но сбор/пчёлы — по правам (сейчас сбор доступен всем; это известное ограничение).
- **Ночь/дождь:** производство ×0.5.
- **Снежный биом:** штраф, смягчается геном «морозостойкость».
- **Лимит мёда:** 5 + восковые рамки, максимум 8.
- **Износ рамок:** уменьшается на 1 за сбор, на нуле исчезает.

## 4. Известные ограничения 0.2.0-SNAPSHOT

- Ресурспак собран под форматы 34–99; на 26.3 проверить фактическую загрузку.
- Кастомная модель улья — ItemDisplay поверх ванильного блока, без InteractionEntity.
- Охрана, медведь, босс, пасека-мультиблок — следующие шаги 0.2.
- Королева привязана к улью: отдельного предмета «матка» пока нет.
- Ресурсы крафтов-предметов не защищены от использования в чужих рецептах.
- Ванильные пчёлы могут наполнять блок, но HiveWorks синхронизирует уровень и перехватывает бутылочку/ножницы.

## 5. Если что-то упало

Собрать:

1. `logs/latest.log` (полностью).
2. Вывод `/hive admin stats`.
3. Версию Paper (`/version`) и Java (`java -version`).
4. Что делали до ошибки.

Складывать в issue: `https://github.com/xuviga/HiveWorks/issues`.
