## 1. Идея

HiveWorks превращает ванильный улей из «нажми ПКМ» в маленькую экосистему:
игрок ловит пчёл, заселяет улей, создаёт условия (цветы, рамки, режим),
получает мёд разного качества и строит пасеку как профессию.

**Формула:** `поймал → заселил → создал условия → собрал → скрафтил → улучшил`.

## 3. Ядро v0.1

### 3.1. Ульи и тиры

| Тир | Блок | Пчёлы | Рамки | Бонус |
|---|---|---|---|---|
| I | Дубовый улей | 3 | 1 | — |
| II | Еловый улей | 4 | 2 | +10% скорость |
| III | Улей из тёмного дуба | 5 | 3 | +10% качество |
| IV | Аметистовый улей | 6 | 4 | +15% шанс редкой пчелы |

- Апгрейд: крафт «текущий улей + материалы». Пчёлы, рамки и мёд сохраняются.
- Блок — ванильный `BEEHIVE`/`BEE_NEST` с PDC-меткой. Визуально тиры различаются
  предметом-иконкой и лором; кастомные модели — в 0.2.
- Лимиты: 4 улья на чанк, 32 на игрока (настраивается правами).

### 3.2. Рамки

Рамка — расходник, вставляется в слот улья. Износ — за каждый сбор.

| Рамка | Эффект | Износ |
|---|---|---|
| Восковая | +1 к максимуму мёда | 32 сбора |
| Медовая | +25% скорость производства | 64 сбора |
| Маточная | +15% к качеству селекции, +шанс маточного молочка | 16 сборов |
| Прополисная | −50% шанс укуса, +прополис | 48 сборов |
| Аметистовая | +0.08 к итоговому качеству | 128 сборов |

- Максимум мёда: `5 + количество восковых рамок`, не выше 8.
- Рамки крафтятся, ломаются и являются ходовым товаром.

### 3.3. Производство и качество

**Базовая скорость:** 1 уровень мёда за 4 минуты при 3 пчёлах и 3+ видах цветов.
Полный улей — около 20 минут.

**Множитель скорости:**

```
speed = bees_factor × flowers_factor × frame_bonus × tier_bonus × time_penalty
```

| Фактор | Значение |
|---|---|
| `bees_factor` | `занятые_слоты / 3`, максимум 1.0 (для тиров выше — до 1.5) |
| `flowers_factor` | 0 видов — 0.25; 1–2 — 0.6; 3–4 — 1.0; 5+ — 1.15 |
| `frame_bonus` | +25% за медовую рамку |
| `tier_bonus` | +10% на II тире |
| `time_penalty` | ночь или дождь — ×0.5; снежный биом без укрытия — до ×0.5 |

- Радиус клумбы — 8 блоков, учитываются цветы и цветущие растения.
- Офлайн-производство: до 8 часов (настраивается), считается при загрузке чанка.
- Без цветов производство не останавливается, но падает до 25% и качество не растёт.

**Качество** считается в момент сбора:

```
score = 0.60 × flower_score + 0.25 × frame_score + 0.15 × purity_score
```

| Компонент | Формула |
|---|---|
| `flower_score` | `min(виды/5, 1)`, редкие цветы (торицвет, ландыш, кактусовый, дикие) с весом 1.5 |
| `frame_score` | сумма весов рамок / максимум |
| `purity_score` | средняя чистота пчёл / 100 |

| Score | Ступень |
|---|---|
| < 0.35 | обычный |
| 0.35 – 0.60 | хороший |
| 0.60 – 0.85 | элитный |
| ≥ 0.85 | легендарный |

- Пыльца: +0.10 к следующему сбору (не суммируется).
- Аметистовая рамка: +0.08.
- Потолок — 1.0.

**Сбор:**
- Пустой рукой / через GUI — бутылочки мёда по числу уровней.
- Ножницами — соты по числу уровней (без бутылочек).
- Ванильные механики (бутылочка, ножницы, костёр) не ломаются: GUI открывается
  только пустой рукой, в sneak или через предмет «Гид пасечника».

### 3.4. Пчёлы

**Предмет:** «Пчела в банке» — PDC-карточка с видом, генами и уникальным UUID.

**Гены (0–100):**

| Ген | Влияние |
|---|---|
| Продуктивность | +мёд за цикл |
| Скорость | −время цикла |
| Морозостойкость | снижает штраф снежного биома |
| Нрав | шанс укуса при обслуживании |
| Чистота линии | вес при селекции и качестве |

**Виды (13):**

| # | Вид | Биом | Редкость |
|---|---|---|---|
| 1 | Лесная | forest | обычная |
| 2 | Луговая | meadow, plains, sunflower_plains | обычная |
| 3 | Таёжная | taiga, old_growth_* | обычная |
| 4 | Болотная | swamp, mangrove_swamp | обычная |
| 5 | Джунглевая | jungle, bamboo_jungle | обычная |
| 6 | Саванная | savanna, badlands | обычная |
| 7 | Пустынная | desert | обычная |
| 8 | Снежная | snowy_plains, ice_spikes | обычная |
| 9 | Грибная | mushroom_fields | обычная |
| 10 | Цветочная | flower_forest, cherry_grove | редкая |
| 11 | Аметистовая | amethyst_geode | редкая |
| 12 | Незерская | crimson_forest, warped_forest | редкая |
| 13 | Бледная | pale_garden (1.21.4+) | редкая |

- Редкие виды дают +5–10 к базовым генам и уникальную модель банки.
- Версии без `pale_garden` просто не спавнят вид 13 (проверка при старте).

**Селекция (v0.1):**

- 2 пчелы в улье + 1 маточная ячейка + 30 минут → потомок.
- По каждому гену: 50/50 от родителей, затем ±5 случайно; 10% шанс мутации +10.
- Чистота потомка = среднее совпадение генов родителей.
- Потомок занимает свободный слот; при отсутствии места — ошибка без потери ресурсов.

**Королева** — 0.2 (см. §13).

### 3.5. Режимы улья

| Режим | Эффект | Статус |
|---|---|---|
| Пасека | производство мёда | v0.1 |
| Опыление | +рост культур в радиусе 5 (мягко, с потолком) | v0.1 |
| Сбор | пчёлы носят пыльцу | v0.1 |
| Охрана | пчёлы-стражи бьют враждебных мобов | v0.2 |

- Опыление: +5% к скорости роста за каждые 3 пчелы, максимум +15%.
- Не заменяет костную муку, не влияет на деревья и грибы.

### 3.6. Продукты v0.1

| Продукт | Источник | Применение |
|---|---|---|
| Мёд (4 сорта) | сбор бутылочкой | еда, крафты, медовуха |
| Соты | сбор ножницами | переплавка в воск |
| Воск | переплавка сот | свечи, рамки, крафт ульев |
| Прополис | сбор с прополисной рамкой | покрытие брони (+15% прочности) |
| Маточное молочко | редкий дроп, маточная рамка | селекция, зелья |
| Пыльца | режим «Сбор» | +0.10 к следующему качеству |

**Крафты v0.1:**

- Ульи I–IV.
- Рамки: восковая, медовая, маточная, прополисная, аметистовая.
- Сачок, банка для пчёл, дымарь (снижает шанс укуса).
- Свечи 4 цветов: аура +5% роста в радиусе 4, максимум 2 свечи на участок.
- Медовуха 3 сортов: мёд + пшеница + бутылка → бочка 10 минут.
  - луговая: сытость + скорость (3 мин);
  - лесная: регенерация I (10 сек);
  - элитная: ночное зрение (5 мин).
  - Баффы не влияют на PvP; отключаются в конфиге.
- Зелье регенерации из маточного молочка.
- Маточная ячейка (воск + мёд + маточное молочко).

Пчелиный яд и покрытие оружия — 0.2 (боевой баланс).

### 3.7. Атлас пчёл

- GUI-коллекция: 13 видов, открытые гены, прогресс.
- Открытие вида — первая пойманная пчела этого вида.
- Награды за полноту: рецепты, косметические банки, титул в GUI.
- Отдельная вкладка «Рекорды»: лучший мёд, легендарные сборы.

### 3.8. Мир v0.1

| Объект | Поведение |
|---|---|
| Дикий рой | 5–8 ванильных пчёл у цветов на рассвете; ловится сачком; исчезает ночью |
| Лиса-сладкоежка | ночью идёт к улью с мёдом > 0, крадёт 1 уровень и убегает; отпугивается дымарём |

- Рой не спавнится в радиусе 32 блоков от чужой пасеки (анти-фарм).
- Лиса не трогает ульи с прополисной рамкой.
- Медведь-разоритель, босс и стражи — 0.2–0.3.

## 7. Данные

### SQLite

```sql
CREATE TABLE hives (
  id           INTEGER PRIMARY KEY,
  world        TEXT NOT NULL,
  x            INTEGER NOT NULL,
  y            INTEGER NOT NULL,
  z            INTEGER NOT NULL,
  owner_uuid   TEXT NOT NULL,
  tier         INTEGER NOT NULL,
  mode         TEXT NOT NULL,
  honey        REAL NOT NULL,
  last_tick    INTEGER NOT NULL,
  created_at   INTEGER NOT NULL,
  UNIQUE(world, x, y, z)
);

CREATE TABLE hive_bees (
  hive_id      INTEGER NOT NULL,
  slot         INTEGER NOT NULL,
  bee_uuid     TEXT NOT NULL,
  species      TEXT NOT NULL,
  gene_prod    INTEGER NOT NULL,
  gene_speed   INTEGER NOT NULL,
  gene_cold    INTEGER NOT NULL,
  gene_temper  INTEGER NOT NULL,
  purity       INTEGER NOT NULL,
  PRIMARY KEY (hive_id, slot)
);

CREATE TABLE hive_frames (
  hive_id      INTEGER NOT NULL,
  slot         INTEGER NOT NULL,
  frame_type   TEXT NOT NULL,
  uses_left    INTEGER NOT NULL,
  PRIMARY KEY (hive_id, slot)
);

CREATE TABLE players (
  uuid             TEXT PRIMARY KEY,
  name             TEXT NOT NULL,
  discovered       TEXT NOT NULL DEFAULT '',
  total_harvests   INTEGER NOT NULL DEFAULT 0,
  total_honey      INTEGER NOT NULL DEFAULT 0,
  legend_harvests  INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE schema_version (version INTEGER NOT NULL);
```

- PDC-ключи предметов: `hiveworks:kind`, `hiveworks:bee_uuid`, `hiveworks:species`,
  `hiveworks:genes`, `hiveworks:purity`, `hiveworks:quality`, `hiveworks:uses`.
- `bee_uuid` защищает от дублирования: одна пчела — один UUID в БД/предмете.

### YAML-фолбэк

Та же структура в `data/hives.yml`, `data/players.yml`. Миграция YAML → SQLite при
смене `storage.type`, как в AurumAuction.

**Режимы:** `OFF` — без пака; `URL` — внешняя ссылка; `EMBEDDED` — встроенный
HTTP-сервер на JDK `com.sun.net.httpserver` (без зависимостей).

**Структура:**

```

      bee_jar_forest.json ... bee_jar_pale.json     (13)

      comb.json, wax.json, propolis.json,
      royal_jelly.json, pollen.json                 (5)
```

## 10. Производительность и безопасность

### Производительность

- Тик ульев — пакетно раз в 20 секунд, только загруженные чанки.
- Индекс ульев по чанку; никаких `getChunkAt` с загрузкой.
- Открытые GUI обновляются раз в секунду, закрытые — никогда.
- Лимиты ульев на чанк/игрока; отключаемые фичи из конфига.

### Безопасность и эксплойты

- Уникальный UUID пчёл + проверка при вставке/извлечении.
- Офлайн-кап и анти-AFK: без цветов производство падает до 25%.
- Укус: яд + урон, но не смертельный (настраивается).
- Воровство: чужой сбор запрещён по умолчанию; лиса крадёт максимум 1 уровень.
- Регионы: в 0.1 — blacklist миров; в 0.3 — опциональный WorldGuard-хук.
- Защита от дюпа: запрет вставки пчелы с занятым UUID, очистка PDC при крафте.

## 15. Критерии успеха 0.1

- Полный цикл проходится без админ-команд за 1 игровую сессию.
- Пасека из 4 ульев даёт стабильный доход предметами, но требует ухода.
- Легендарный мёд достигается только продуманной клумбы + рамок + линии.
- Ни одного дюпа, краша и лага на 100 ульях при 50 игроках.
- Игрок понимает механику без вики — через `/hive guide` и лор.
